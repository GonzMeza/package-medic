# PackageMedic brand

PackageMedic's identity combines a software package with a diagnostic pulse. The mark communicates dependency health without presenting the product as a healthcare service.

## Assets

- `packagemedic-logo.png` — 1024×1024 primary square logo.
- `packagemedic-icon.png` — 256×256 optimized repository and NuGet icon.
- `packagemedic-social-preview.png` — 1280×640 GitHub Social Preview.

## Color palette

| Role | Color | Hex |
| --- | --- | --- |
| Background | Deep navy | `#07111F` |
| Package | Diagnostic cyan | `#35D4FF` |
| Pulse | Healthy mint | `#55E6A5` |
| Primary text | Off-white | `#F7FAFC` |
| Secondary text | Cool gray | `#C7D7E5` |

## Typography

Use a modern geometric sans-serif such as Inter, Geist, or Segoe UI. Product copy should be direct, technical, and calm.

## Usage

- Preserve the logo's proportions and clear space.
- Prefer the deep navy background supplied with the raster assets.
- Keep the cyan package and mint pulse colors together.
- Do not add a medical cross, stethoscope, pill, or healthcare claim.
- Do not stretch, rotate, recolor, outline, or place effects over the mark.
- Use the tagline exactly as: **A dependency doctor for .NET projects**.
